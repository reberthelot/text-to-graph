Scoring rules

Unique RDF triples are compared after JSON-LD expansion. Local extraction URIs and blank nodes are aligned one to one; catalogue URIs stay fixed.

Finite numerical values compare by value (7 = 7.0). Literal text, language tags and other datatypes retain RDF semantics.

Every triple counts, including labels and type statements. Additional facts count as false positives, even when an exercise calls them optional.

Both graphs empty: F1 = 1. Empty prediction with nonempty reference: precision = recall = F1 = 0.

Alignment searches up to 100,000 states or 3 seconds. If unfinished, scores are labelled lower bounds.
